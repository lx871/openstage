# Security Policy

## Reporting a Vulnerability

Please report security issues privately to the maintainers via GitHub Security Advisories
(`Security` → `Report a vulnerability`) or by opening a private issue.

We aim to acknowledge within 3 business days and to ship a fix or mitigation
within 90 days. Please do not disclose publicly until a fix is available.

## Scope

This policy covers the `openstage` packages under `packages/*` and tools under
`tools/*`, including gateway endpoint handling, storage import validation, and
extension capability enforcement.
